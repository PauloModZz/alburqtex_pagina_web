# Fotos pendientes

Todas las secciones nuevas muestran un bloque "Foto próximamente" (mismo
estilo que ya usa el catálogo para productos sin foto) mientras no exista el
archivo real en la ruta indicada. En cuanto subas la foto con el nombre
exacto de abajo a `public/`, aparece sola — no hay que tocar código.
